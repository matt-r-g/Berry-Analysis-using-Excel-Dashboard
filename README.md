# Berry-Analysis-using-Excel-Dashboard

📊 Berry Sales Dashboard – Excel Analytics Project
🍓 Overview
This project showcases an interactive Excel dashboard designed to analyse berry sales performance across different categories, time periods, and regions.
It combines data cleaning, pivot tables, slicers, and visualisations to deliver a clear, dynamic view of sales trends.

🎯 Project Objectives
- Analyse overall sales performance for various berry types
- Identify trends and patterns across time periods
- Provide an interactive dashboard for quick insights
- Demonstrate Excel skills including pivot tables, slicers, and charting

🧰 Tools & Techniques Used
📑 Excel Features
- Pivot Tables
- Pivot Charts
- Slicers for interactive filtering
- Data cleaning and transformation
- Conditional formatting
- Dynamic charts and KPIs

Insights into the dataset

---

  
1. **Are there seasonal patterns in berry sales across different regions?**  
Looking at the quarterly sale, we found that there q4 was better in 2023 while q3 was for 2024, also there was no data for north and south for the year 2024 for quarter 4

2. **How does demand for red berries compare to black berries across regions?**  
The south region has the most sales of black berries while east lowest sales of black berries.

3. **Can any correlations be drawn between average berry weight and regional sales volume?**  
Yes, The scatter plot does in fact shows correlation for each region. Looking at, it shows positive correlation.

4. **What are the sales growth trends for each berry type across the last two years?**  
The line shows trend overtime; we found that there wasn’t consistent winner from 2023 till mid-2024. Q4 for 2024 shows a massive decline due to no data available.
